# FABRIK — Brutalist Industrial Design Studio

> **Winner — Design2Code Hackathon**

A pixel-perfect implementation of a brutalist industrial studio website built for the Design2Code challenge.

🔗 **[Live Demo](https://fabrik-design2code.vercel.app)**

## Stack

- React · TypeScript · Vite · TailwindCSS · GSAP

## Features

- Brutalist industrial UI with custom cursor and smooth scroll animations
- Dark/Light mode toggle
- Modular component architecture — Hero, ProductGrid, Timeline, CaseStudies, Contact
- GSAP ScrollTrigger-powered animations
- Production-ready, fully responsive

## Run Locally

```bash
npm install
npm run dev
```
